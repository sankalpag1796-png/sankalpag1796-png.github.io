Privacy Policy — Trade-Wizard

Last updated: October 24, 2026

About this application

Trade-Wizard is a private trading journal and reporting application operated by its owner for personal use. It is not offered as a public service.

Google account access

With the owner's authorization, Trade-Wizard may use Google's Gmail API to read email messages and attachments needed for personal recordkeeping, including broker contract notes. Any additional Google permissions are requested separately and only when needed.

Data use and storage

Google account data is used only to provide the application's personal recordkeeping and reporting functions. Data may be processed and stored on the owner's private server as required for those functions. Access to the server is restricted by the owner's private access controls.

Sharing and disclosure

The application is intended for the owner's personal use. Google account data is not sold. Data is not shared with third parties except where necessary to operate the application, comply with law, or protect security, and only as applicable to the actual operation of the service.

Security and retention

The owner uses access controls to protect the application and its stored data. No internet-connected system can guarantee absolute security. Data is retained only as needed for personal recordkeeping and reporting, subject to applicable legal requirements.

Revoking access

The owner may revoke Trade-Wizard's access through their Google Account security settings. Revoking access prevents future authorized API access but may not automatically delete data already stored by the application.

Google API Services User Data Policy

Trade-Wizard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
